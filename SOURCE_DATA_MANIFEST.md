Extended figures are rendered by `scripts_R/extended_data/` and retained as
`outputs/appendix/extended_data_figure_*`. Their principal input layers are
`data/processed/`, the allowlisted computational files in `manuscript_notes/`, `outputs/tables/`,
`outputs/summaries/`, `outputs/calibrations/`, and `outputs/metadata/`.

Run metadata record configuration and source hashes, dependency versions, row
counts, and audited artifact digests. `ANALYSIS_PROTOCOL.md` defines which
artifacts belong to the current release and the claim limits attached to them.
